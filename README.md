# Banglu — downloads

This repository holds only the published installers and update pointers for
Banglu (বাংলু), the Bengali phonetic keyboard and editor family:

- Android keyboard (APK for testers; the store build is on Google Play)
- বাংলু এডিটর (desktop editor: macOS DMG, Windows MSI, Linux DEB)
- বাংলু টাইপার (Windows input method MSI + its update pointer)
- Browser extensions (Chrome, Firefox)

Stable links: https://github.com/Shahabul87/banglu-kmp/releases/download/downloads/…
Website: https://www.bangluweb.com

The source code, the typing engine and the dictionary data are proprietary
and are not published here or anywhere else.
